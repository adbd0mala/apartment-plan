# مخطط ومجسم الشقة (مرحلة المباني)

الموقع: **https://adbd0mala.github.io/apartment-plan/**

مصدر واحد للحقيقة: `src/geometry.py` (إحداثيات الحوائط/الأبواب/الشبابيك/الأعمدة بالمتر). كل المخرجات بتتولّد منه آليًا.

## ملفات الموقع (جذر الريبو – GitHub Pages)
| ملف | وصف |
|---|---|
| `index.html` | الصفحة الرئيسية |
| `viewer.html` | **مجسم 3D نسخة الصور** – 36 زاوية، بتشتغل على أي موبايل |
| `model.html` | مجسم 3D تفاعلي (model-viewer، WebGL + AR) – الموديل مضمّن جواه |
| `plan.html` | المخطط 2D + بيانات الإحداثيات JSON |
| `plan.png` / `plan.pdf` / `plan.svg` | المخطط الأفقي (A3، 1:50) |
| `plan.dxf` | للأوتوكاد – طبقات منفصلة |
| `model.glb` | الموديل 3D (Y-up، للعارضات والموبايل) |
| `apartment_3d.obj` | للـ SketchUp / Blender / 3ds Max |

## التعديل
1. عدّل الأرقام في `src/geometry.py` (طول غرفة، موضع باب، ارتفاع حائط…).
2. `pip install -r requirements.txt` ثم `bash build.sh` → يعيد توليد 2D + DXF + 3D وينسخها لجذر الريبو.
3. (اختياري) `bash build_frames.sh` لإعادة تصوير نسخة الصور (يحتاج Node + Playwright).
4. `git commit && git push` → الموقع يتحدّث تلقائيًا.

## الاصطلاحات
- المحاور زي الكروكي: x يمين، y فوق. البلكونة يمين، المطبخ تحت شمال، باب الشقة تحت يمين الصالة.
- حوائط خارجية 0.20، داخلية 0.10. الارتفاعات: سقف 3.00، أبواب 2.20، قوس الطرقة 2.40، سور البلكونة 1.00، حائط بار المطبخ 1.50.
- `FLAGS` في `geometry.py` = البنود غير المؤكدة اللي بتظهر بالأحمر على اللوحة.
